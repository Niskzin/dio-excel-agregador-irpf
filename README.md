# Agregador de Informações para Imposto de Renda

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de aplicar conhecimentos de Excel na criação de uma ferramenta prática para organização de informações relacionadas à declaração de Imposto de Renda.

A proposta é reunir diferentes tipos de informações em um único arquivo, facilitando o controle, a organização e a consulta dos dados.

## 🎯 Objetivo

Criar uma ferramenta em Excel capaz de organizar informações importantes para a declaração de Imposto de Renda, utilizando recursos como navegação entre abas, validação de dados, cálculos automáticos, indicadores e links úteis.

## ⚙️ Funcionalidades

* Menu principal com navegação entre as áreas da planilha;
* Cadastro de dados pessoais;
* Organização de rendimentos;
* Controle de informações bancárias e informes;
* Registro de bens e direitos;
* Organização de pagamentos;
* Controle de investimentos;
* Listas suspensas para facilitar o preenchimento;
* Validações para reduzir erros de entrada;
* Cálculos automáticos de totais;
* Resumo geral das informações;
* Indicadores de quantidade de registros;
* Gráfico para visualização dos valores;
* Links rápidos para páginas oficiais;
* Interface organizada e de fácil utilização.

## 📊 Estrutura do projeto

O arquivo Excel está dividido nas seguintes áreas:

* **MENU** – Página inicial e navegação;
* **DADOS_PESSOAIS** – Informações básicas do titular;
* **RENDIMENTOS** – Registro de rendimentos;
* **BANCOS_E_INFORMES** – Controle de contas, saldos e informes;
* **BENS_E_DIREITOS** – Organização de bens e direitos;
* **PAGAMENTOS** – Registro de pagamentos e despesas;
* **INVESTIMENTOS** – Controle de investimentos;
* **RESUMO** – Indicadores e visualização geral;
* **LINKS_UTEIS** – Acessos rápidos a páginas oficiais;
* **LISTAS** – Dados utilizados nas validações da planilha;
* **README_PROJETO** – Informações sobre a construção da ferramenta.

## 🚀 Como utilizar

1. Baixe ou abra o arquivo `Agregador_IRPF_DIO.xlsx`.
2. Acesse a aba **MENU**.
3. Navegue até a área desejada.
4. Preencha os campos disponíveis.
5. Utilize as listas suspensas quando disponíveis.
6. Registre os documentos e informações correspondentes.
7. Acesse a aba **RESUMO** para visualizar os indicadores e valores consolidados.

## 📈 Resultados

A ferramenta permite centralizar diferentes informações em um único arquivo, facilitando a organização dos dados e proporcionando uma visão mais clara dos valores registrados.

O projeto também demonstra a aplicação prática de recursos do Excel para criação de uma ferramenta organizada, funcional e amigável.

## 📚 Aprendizados

Durante o desenvolvimento do projeto foram aplicados conceitos relacionados à organização e tratamento de dados no Excel, criação de tabelas, validação de informações, utilização de fórmulas, construção de gráficos e criação de uma interface de navegação.

Além disso, o projeto permitiu praticar a documentação técnica e a utilização do GitHub para disponibilização e compartilhamento do projeto.

## ⚠️ Observação

Este projeto possui finalidade **educacional e organizacional** e foi desenvolvido para demonstrar os conhecimentos adquiridos durante o desafio.

Os dados presentes inicialmente na planilha são **demonstrativos** e devem ser substituídos pelos dados reais caso a ferramenta seja utilizada para organização pessoal.

A ferramenta não substitui a declaração oficial do Imposto de Renda, a conferência das regras vigentes da Receita Federal ou a orientação de um profissional qualificado.
